# Agent Skills（服务端托管）

本目录由 AI Chat tab（`chat.html`）与 `scripts/agent_server.py` 管理。

- 每个子目录需含 `SKILL.md`（Cursor Agent Skill 格式）
- 可通过 Chat 页「从本机导入」把 `~/.cursor/skills/` 或 `~/.cursor/skills-cursor/` 中的 skill 复制到此处
- 发送对话时，选中的 skill 正文会随用户诉求一并交给配置的 Agent

配置文件（可选）：`.agent_config.json`（含 API Key 时请勿提交到公开仓库）
